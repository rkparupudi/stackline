Familiar patterns, agent edition

An agent is still a distributed system. These classic patterns from the system design track show up in every serious agent platform. Each name links to its animation.

Classic patternHow it applies to agents
Message queueTask queues for agent jobs; idempotent workers, because a step may run twice.
Idempotency keysEvery side-effecting tool call carries a key, so a replayed step can’t refund or email twice.
Circuit breakerFall back to another model or provider when one is failing or timing out.
Retries with backoffModel APIs return rate-limit and overload errors; retry with jitter and a cap.
Rate limitingPer-user and per-agent token and cost budgets, not just requests per second.
CachingCache tool results and embeddings; many providers also offer prompt caching for repeated context.
SagaMulti-step agent actions need compensations when a later step fails.
BulkheadSeparate concurrency limits per tool, so one slow API can’t stall every agent.
